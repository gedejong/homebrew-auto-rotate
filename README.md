# gedejong/homebrew-auto-rotate

Homebrew tap for [Auto-Rotate](https://github.com/gedejong/auto-rotate) — automatically
deskew and turn upright every page of a PDF.

```bash
brew install --cask gedejong/auto-rotate/auto-rotate
```

The desktop app's orientation/OCR features need Tesseract (and OCRmyPDF for OCR):

```bash
brew install tesseract ocrmypdf
```

> The 0.1.0 build is Apple Silicon, macOS 14+, and not yet notarized — on first launch,
> right-click the app and choose **Open**.
